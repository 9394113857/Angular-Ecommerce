# Project Updates

This directory is the shared progress-tracking area for the **Angular storefront and client-side ecommerce experience** repository.

## Purpose
- Keep a consistent project plan across the Angular Ecommerce and Backend Auth Service repositories.
- Record planned work, implementation status, and notable updates.
- Use the same Markdown filenames in both repositories so the two workstreams are easy to compare.

## Tracking files
- [TODO.md](./TODO.md) — planned and in-progress work.
- [IMPLEMENTATION_STATUS.md](./IMPLEMENTATION_STATUS.md) — current implementation snapshot and verification notes.
- [CHANGELOG.md](./CHANGELOG.md) — dated project-update history.
- [BRANCH_WORKFLOW.md](./BRANCH_WORKFLOW.md) — coordinated branch and commit conventions.

## Working branch

`feature/project-documentation-tracking`

This documentation branch is created from `main` in both repositories. Keep repository-specific code changes in focused feature branches; coordinate cross-repository features by using the same feature branch name in each repository.
